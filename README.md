# Actividad práctica: Introducción a JavaScript

Actividad práctica de la Conferencia #5 de Programación Web. Practica la sintaxis básica de JavaScript con ejercicios que muestran sus resultados en la consola del navegador

## Contenido del proyecto

- `index.html`: página que enlaza el script y resume los ejercicios
- `script.js`: código JavaScript con la solución de los 5 ejercicios

## Ejercicios

1. Cálculo del área de un círculo con `Math.PI`
2. Saludo a cada estudiante de un array con `for...of`
3. Cuenta regresiva desde 5 con `while`
4. Comparación estricta con `===` y explicación de qué pasaría con `==`
5. Función que indica si un número es par o impar usando `%`

## Cómo ejecutarlo

1. Descarga o clona este repositorio
2. Abre `index.html` en el navegador
3. Abre las herramientas de desarrollador 
4. Ahí aparecen los resultados de cada ejercicio
